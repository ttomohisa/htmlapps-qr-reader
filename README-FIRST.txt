QR Reader
=========

1. Read README.ja.md.
2. Run build-standalone.bat on Windows 10/11.
3. Open dist\index.html.
4. For camera testing, prefer HTTPS (for example GitHub Pages) because browser camera rules vary.
5. Test on an actual smartphone: camera startup, torch, zoom slider, swipe zoom, pinch zoom, image scan, camera switch, and history.

Do not edit dist\index.html manually. Edit src\index.template.html and rebuild.
